# Rapira syntax highlighting for VS Code

> [!WARNING] FULLY AI GENERATED SLOP, YOU HAVE BEEN WARNED

This directory is a minimal VS Code extension that registers the Rapira language
for `.rap` and `.рап` files and supplies a TextMate grammar.

To try it locally, open this directory in VS Code and run **Extensions: Install
from VSIX** after packaging it, or press `F5` to launch an Extension Development
Host. Packaging can be done with `npx @vscode/vsce package` when Node.js is
available.

The grammar is also usable by editors that support TextMate grammars. Its scope
name is `source.rapira` and the grammar file is `syntaxes/rapira.tmLanguage.json`.
