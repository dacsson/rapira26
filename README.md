## Как пользоваться?

Собери проект:
```
git clone https://gitflic.ru/project/artjom/rapira26
cd rapira26
# Получить бинарник в target/release/rapira26
cargo build --release
# Или если хочется установить на уровне системы
cargo install --path .
# Собери рантайм
make -C runtime/
export RAPIRA_RUNTIME=runtime/
```

Запусти пример:
```
~/Projects/rapira26  =>  target/release/рапик --запуск doc/привет.рап
Привет, это Рапира26!
```

### Модули

Файлы модулей с расширением `.rap` или `.рап` ищутся рядом с импортирующим файлом:

```rapira
подкл "матеша" (удвоить)
вывод: удвоить(21)
```

`рапик main.rap` сам найдёт `math.rap`, рекурсивно загрузит его зависимости и соберёт все модули в один `.rbc`. Код верхнего уровня выполняется один раз в порядке зависимостей. Циклические импорты пока запрещены.

Модули ищутся по порядку: рядом с импортирующим файлом, в каталогах из
`--путь-модулей` (или `RAPIRA_PATH`), затем в стандартной библиотеке. Путь к
стандартной библиотеке можно задать:

```bash
рапик --путь-стд /usr/lib/rapira26/std main.rap
# или
RAPIRA_STD=/usr/lib/rapira26/std рапик main.rap
```

Если путь не задан, `рапик` ищет `std` рядом с исполняемым файлом, а также в
`lib/rapira26/std` и `share/rapira26/std` относительно префикса установки.

## Использование ИИ 

В разработке активно использовался Claude Code Opus 4.6. К примеру многие тесты на языке "Рапира" были сгенерированны ИИ на основе препринта, а также лексер и парсер по большей части.
